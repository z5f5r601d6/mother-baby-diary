# 如何花少钱买好药？这两类药你不可不知哦！

> 更新时间：2026-09-17 (UTC+8)

目前市面上的药品种类繁多，

药价虚高不实，质量更是参差不齐,

该如何选择呢？

这篇文章来告诉您

**第一类：国家基本药物**

**世界卫生日****发展历史**
世界卫生日是一次全球性机会，注重于影响国际社会的主要公共卫生问题。
**设立宗旨**
动员世界各国人民普遍关心和改善当前的卫生状况，提高人类健康水平。
**卫生条例**
2005年通过的《国际卫生条例（2005）》于2007年6月15日起实施。
**什么是国家基本药物？**
国家基本药物是由国家相关部门统筹，汇聚医学、药学、药物经济学等多方面专家，精挑细选出来的药物，确保临床防治必需、安全有效、价格合理、使用方便以及中西药并重。

**选择国家基本药物的4点理由**
**省钱**

国家基本药物不仅价格合理，还可以用医保报销，报销比例也高于非基本药物，能够为患者节省不少钱哦。

**用药合理**

国家通过各种政策、法规、指导意见等手段，规范国家基本药物的使用，避免过度用药。

**安全有效**

国家基本药物不是廉价药，而是经过长期临床实践检验证明安全有效的首选药物。

国家对基本药物实行全品种覆盖抽验，全流程的追踪检查，质量更可靠，用药更安全。

**购买方便**

国家规定，政府办各基层医疗卫生机构即乡镇卫生院、社区卫生服务机构都需配备和使用国家基本药物，并确保基本药物供应的可持续性。患者少跑路、少花钱，在家门口就能买到便宜好药。

**第二类：国家集中采购药**

**世界卫生日****发展历史**
世界卫生日是一次全球性机会，注重于影响国际社会的主要公共卫生问题。
**设立宗旨**
动员世界各国人民普遍关心和改善当前的卫生状况，提高人类健康水平。
**卫生条例**
2005年通过的《国际卫生条例（2005）》于2007年6月15日起实施。
**什么是国家集中采购药？**
国家集中采购药，也称集采/带量采购药。是国家医保局、工业和信息化部、财政部、人力资源社会保障部等部门牵头，组织各省组成采购联盟，对药品进行集中采购，以量换价，通过大型“团购”方式采购的药品，让群众用上质优价廉药品。

**选择国家基本药物的2点理由**
**价格更低**

同一个药品，进入集采后，平均降价53%。比如刚进入第6批集采品种的甘精胰岛素，集采前价格为180元/支，现在降至70元/支左右，降幅高达61%。

**降价不降质**

目前国家组织完成的6个批次，共234种临床常用集采药品中，除了“国产药”（仿制药），还有“进口药”（原研药）。其中“国产药”是通过质量和疗效一致性评价，质量与“进口药”一致的好药，并有相应的标识。药品降价不降质，老百姓以比较低廉的价格就能用上质量更高的药品。
